Sentence Structure (โครงสร้างประโยค)

Grammar (ไวยากรณ์) คือ กฎเกณฑ์และโครงสร้างของภาษาที่ช่วยให้เรานำคำศัพท์ (Vocabulary) มาร้อยเรียงเป็นประโยคเพื่อสื่อสารได้อย่างถูกต้องและเข้าใจตรงกัน


ในภาษาอังกฤษ แผนผังการเรียน Grammar จากพื้นฐานไปจนถึงระดับสูง มักจะแบ่งออกเป็นหมวดหมู่หลักๆ ดังนี้

1. โครงสร้างประโยคพื้นฐาน (Sentence Structure)/b>

Subject + Verb: โครงสร้างที่สั้นที่สุด เช่น Birds fly. (นกบิน)

Subject + Verb + Object: โครงสร้างยอดนิยม เช่น I love English. (ฉันรักภาษาอังกฤษ)

Subject + Verb + Complement: ประโยคที่ใช้กริยาช่วยหรือ Linking Verb เพื่อบอกสถานะ เช่น She is a doctor. (เธอเป็นหมอ)

2. ความสอดคล้องของประโยค (Subject-Verb Agreement)

ประธานเป็นเอกพจน์ (คนเดียว/สิ่งเดียว) → กริยาต้องเติม s/es (ใน Present Simple) เช่น He walks.

ประธานเป็นพหูพจน์ (หลายคน/หลายสิ่ง) → กริยาไม่ต้องเติม s/es เช่น They walk.

3. วาจกหรือมุมมองของประโยค (Voice)

Active Voice (ประธานเป็นคนทำ): The cat chased the mouse. (แมวไล่จับหนู)

Passive Voice (ประธานเป็นผู้ถูกกระทำ): The mouse was chased by the cat. (หนูถูกไล่จับโดยแมว) → โครงสร้างหลักคือ Verb to be + V.3

4. ประโยคเงื่อนไข (Conditional Sentences / If-Clauses)

Type 0 (ความจริงทั่วไป): If it rains, the grass gets wet.

Type 1 (เป็นไปได้ในอนาคต): If I study hard, I will pass the exam.

Type 2 (สมมติในปัจจุบัน/เป็นไปได้ยาก): If I won the lottery, I would buy a house.

Type 3 (เสียดายเรื่องในอดีต/กลับไปแก้ไขไม่ได้): If I had started earlier, I would have finished on time.

5. คำเชื่อมและประโยคความซ้อน (Conjunctions & Clauses)

Relative Clause (ประโยคขยายคำนาม): การใช้ who, which, that, whom, whose เพื่อขยายคำนาม เช่น The man who lives next door is a teacher. (ผู้ชายที่อาศัยอยู่ข้างบ้านเป็นครู)
